Getting started with noxed

From install to your first SSH session, SFTP transfer, database query and Kubernetes cluster in a few minutes.

1. Install noxed

Download the installer for your platform from the download page and run it. noxed doesn't need an account or sign-in.

2. Add an SSH host

  1. Press ⌘T (or Ctrl+T) or click New Connection.
  2. Choose SSH Server.
  3. Enter the host, port and username.
  4. Choose authentication: a password (saved in your OS keychain) or a private key.
  5. Click Test Connection, then save. Open the host from the sidebar to start a session.

Connect using an SSH key

Choose key authentication and enter the path to your private key, for example ~/.ssh/id_ed25519. For safety, noxed only reads keys from ~/.ssh, ~/.config/ssh and ~/.pem.

Import hosts from ~/.ssh/config

In the Connections view, use Import hosts from ~/.ssh/config. noxed lists the hosts it finds and imports the ones you select, including ProxyJump settings.

Use a jump host

In a connection's settings, pick a saved server under Connect via (jump host). noxed connects through it automatically, and chains of jump hosts also work.

3. Browse files with SFTP

In an open SSH session, click Files in the session header to open an SFTP drawer for that server. For a full two-pane browser, add an SFTP Server connection instead. Drag files between panes to transfer them, and press Space to preview a file.

4. Forward a port

Open Tunnels from the sidebar and define a local forward, remote forward or SOCKS5 proxy over a saved connection. Start and stop it with one click. Active tunnels appear in the status bar.

5. Connect to a database or Redis

Add a Database connection for PostgreSQL, MySQL, MariaDB or SQL Server, or pick a SQLite file inside your home folder with Browse…. Redis gets its own Redis connection type. Database tabs open with a schema browser and query editor. Run a query with ⌘Enter, and use the History and Saved tabs to go back to earlier queries.

6. Open a Kubernetes cluster

Add a Kubernetes connection and pick a context from your kubeconfig (~/.kube/config), or import another kubeconfig file. The dashboard covers pods, deployments, services, config, nodes and events. You can stream logs, exec into a pod or start a port-forward from there.

7. Lock noxed when you step away

In Settings, choose a lock method (Touch ID, PIN or password) and an auto-lock timeout. Saved credentials stay locked until you unlock the app.
