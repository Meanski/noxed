Download

Download noxed for macOS, Windows and Linux

noxed is free and open source. Installers for every platform are on the latest GitHub release.

Get the latest release All releases

Choose your platform

PlatformDownloadRequirements
macOS.dmg or .zipApple Silicon (M1 or later). Signed and notarized.
WindowsSetup .exe (NSIS installer)Windows 10 or 11, 64-bit. Code-signed.
Linux.AppImage or .deb64-bit x86. A keyring service such as GNOME Keyring or KWallet.

On the latest release page, look under Assets and pick the file for your platform.

Install on macOS

  1. Download the .dmg from the latest release.
  2. Open it and drag noxed into Applications.
  3. Launch noxed from Applications or Spotlight.

Install on Windows

  1. Download noxed.Setup.<version>.exe from the latest release.
  2. Run the installer.

The installer is signed, but Windows SmartScreen also checks how often a file has been downloaded, so a new release can still show a warning. Click More info → Run anyway to continue.

Install on Linux

AppImage

chmod +x noxed-*.AppImage
./noxed-*.AppImage

Debian / Ubuntu (.deb)

sudo apt install ./noxed_*_amd64.deb

noxed stores credentials through libsecret, so a keyring service must be running. On Debian and Ubuntu, install it with sudo apt install libsecret-1-0.

Updates

Installed builds check GitHub Releases for a new version when they start. noxed asks before downloading anything, and installs the update when you quit.

Build from source

You need Node.js 20 or later and npm.

git clone https://github.com/Meanski/noxed.git
cd noxed
npm install
npm run dist   # installers land in dist/
